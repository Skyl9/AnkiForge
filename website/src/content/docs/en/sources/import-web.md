# Importing Web Pages and Online Articles

Studying from online encyclopedias, technical blogs, or web courses? The AnkiDraft Web Importer extracts only the relevant study content.

## 1. Capturing a Web Page

1. In the **Documents** view, click **Import Web Page**.
2. Paste the article URL (`https://...`).
3. AnkiDraft automatically strips navigation menus, banners, and ads, keeping only headings, paragraphs, tables, code blocks, and illustrations.

## 2. Dynamic Web Pages

If a page requires JavaScript to render its content (single-page apps or interactive courses), enable **Full Browser Rendering** during import so AnkiDraft waits for the complete page text before extracting it.
