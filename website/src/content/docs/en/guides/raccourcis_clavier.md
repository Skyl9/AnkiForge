# Keyboard Shortcuts Reference ⌨️

This page lists the default keyboard shortcuts in AnkiDraft. You can customize any shortcut in **Settings** (<kbd>Ctrl+,</kbd>) > **Keyboard**.

> On macOS, <kbd>Ctrl</kbd> maps automatically to <kbd>Cmd ⌘</kbd>.

## 1. Global Application Actions

| Action | Default Shortcut | Scope | Description |
| :--- | :--- | :--- | :--- |
| **Command Palette** | <kbd>Ctrl+K</kbd> | `Application` | Open the global command palette omnibox |
| **Settings** | <kbd>Ctrl+,</kbd> | `Application` | Open the Settings dialog |
| **Save** | <kbd>Ctrl+S</kbd> | `Application` | Save changes in the active view |
| **Run Primary Action** | <kbd>Ctrl+Return</kbd> | `Application` | Trigger the main action in the active view (generate, run) |
| **Find / Search** | <kbd>Ctrl+F</kbd> | `Application` | Focus the search field in the active view |
| **Import Anki Package (.apkg / .colpkg)** | <kbd>Ctrl+Shift+I</kbd> | `Application` | Open the collection or deck import wizard |
| **Export Anki Cards (.apkg)** | <kbd>Ctrl+Alt+E</kbd> | `Application` | Open the `.apkg` card export dialog |
| **Interactive Guided Tour** | <kbd>F1</kbd> | `Application` | Launch the interactive feature tour |

## 2. Workspace Navigation

| Action | Default Shortcut | Scope | Description |
| :--- | :--- | :--- | :--- |
| **Dashboard** | <kbd>Ctrl+1</kbd> | `Application` | Switch to the Dashboard view |
| **Editor & Browser** | <kbd>Ctrl+2</kbd> | `Application` | Switch to the Note Editor and Card Browser |
| **Documents & Sources** | <kbd>Ctrl+3</kbd> | `Application` | Switch to the Document Hub |
| **Generation & Pipelines** | <kbd>Ctrl+4</kbd> | `Application` | Switch to Batch AI Generation |
| **Quality & Wozniak Audit** | <kbd>Ctrl+5</kbd> | `Application` | Switch to the Wozniak Quality Linter |
| **AI Consultant** | <kbd>Ctrl+6</kbd> | `Application` | Switch to the interactive AI Consultant |

## 3. Note Editor & Formatting

| Action | Default Shortcut | Scope | Description |
| :--- | :--- | :--- | :--- |
| **New Note** | <kbd>Ctrl+N</kbd> | `View` | Create a new flashcard note |
| **Duplicate Note** | <kbd>Ctrl+D</kbd> | `View` | Duplicate the selected note |
| **Delete Note** | <kbd>Delete</kbd> | `View` | Delete the selected note(s) |
| **Bold** | <kbd>Ctrl+B</kbd> | `Widget` | Toggle bold text formatting |
| **Italic** | <kbd>Ctrl+I</kbd> | `Widget` | Toggle italic text formatting |
| **Underline** | <kbd>Ctrl+U</kbd> | `Widget` | Toggle underline formatting |
| **Insert Cloze Deletion** | <kbd>Ctrl+Shift+C</kbd> | `Widget` | Wrap selection in `{{c1::...}}` |
| **Undo / Redo** | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Shift+Z</kbd> | `Widget` | Undo or redo the last edit |
