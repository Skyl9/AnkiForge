# Consultant IA et Connexion aux Assistants MCP

Le **Consultant IA** (<kbd>Ctrl+6</kbd>) est votre assistant pédagogique au sein d'AnkiDraft. Vous pouvez également piloter AnkiDraft depuis votre client IA externe favori grâce au protocole standard **MCP (Model Context Protocol)**.

## 1. Ce que le Consultant IA peut faire pour vous

Posez-lui vos demandes en langage naturel :
- *« Trouve les chapitres de mon cours de cardiologie qui n'ont pas encore de cartes »*
- *« Cherche les doublons dans mon paquet Anatomie et propose une fusion »*
- *« Raccourcis les 10 cartes les plus longues de ce paquet selon les règles de Wozniak »*

## 2. Garde-fou de sécurité : validation humaine en deux temps

Ni le Consultant IA intégré ni un agent externe connecté via MCP ne peut modifier ou supprimer vos cartes sans votre accord :
1. L'assistant prépare ses modifications dans un **lot en attente (Staged Bundle)**.
2. Vous visualisez clairement l'avant/après de chaque carte ajoutée, modifiée ou supprimée.
3. Vous cliquez sur **Appliquer** ou **Rejeter** : vous gardez toujours le contrôle absolu sur votre collection.

## 3. Connecter un client externe (Claude Desktop, Cursor, etc.)

Dans la vue **Consultant IA** > **Serveur MCP**, activez le serveur local et copiez la configuration en un clic pour permettre à votre assistant externe d'interroger vos paquets et vos cours en toute sécurité.
