# Importer des Pages Web et Articles

Vous révisez à partir d'articles encyclopédiques, de blogs techniques ou de cours publiés en ligne ? L'importateur web d'AnkiDraft extrait uniquement le contenu pédagogique pertinent.

## 1. Capturer une page web

1. Dans la vue **Documents**, cliquez sur **Importer une page Web**.
2. Collez l'adresse (`https://...`) de l'article souhaité.
3. AnkiDraft nettoie automatiquement les menus de navigation, bannières et publicités pour ne conserver que les titres, paragraphes, tableaux, blocs de code et illustrations de l'article.

## 2. Pages web dynamiques

Si la page nécessite l'exécution de JavaScript pour afficher son contenu (sites modernes ou cours interactifs), activez l'option **Rendu navigateur complet** lors de l'import : AnkiDraft attendra le chargement complet du texte avant de l'extraire.
