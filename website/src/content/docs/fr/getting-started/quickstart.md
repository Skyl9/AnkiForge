# Prise en Main Rapide

Ce tutoriel vous accompagne pas à pas pour créer, relire et exporter votre tout premier paquet de flashcards vers Anki en moins de 5 minutes.

## Le flux de travail en 5 étapes

1. **Importer un support de cours** : ajoutez un PDF, une vidéo YouTube ou une page web dans la vue **Documents**.
2. **Sélectionner les parties à étudier** : cochez les chapitres ou les pages qui vous intéressent.
3. **Générer des propositions de cartes** : laissez l'IA extraire des questions/réponses atomiques ou rédigez vos propres cartes.
4. **Relire et vérifier la qualité** : corrigez les formulations, ajoutez des formules mathématiques ou de l'audio, et passez le contrôle qualité Wozniak.
5. **Exporter vers Anki** : générez un fichier `.apkg` prêt à être ouvert dans Anki Desktop ou AnkiMobile.

## Étape 1 : Choisir ou créer votre profil

Au premier lancement, AnkiDraft ouvre le profil par défaut. Si vous partagez votre ordinateur ou souhaitez séparer vos matières (ex. *Médecine*, *Langues*), cliquez sur le sélecteur de profil pour créer un espace totalement isolé.

## Étape 2 : Configurer un modèle d'IA (optionnel)

Ouvrez **Paramètres** (<kbd>Ctrl+,</kbd>), puis l'onglet **Fournisseurs IA** :
- **Sans clé payante (100 % local)** : installez [Ollama](https://ollama.com) sur votre machine et choisissez un modèle local.
- **Via une clé API cloud** : renseignez votre clé OpenAI, Google Gemini ou Anthropic Claude. Votre clé est chiffrée dans le trousseau sécurisé de votre système.

## Étape 3 : Importer votre premier document

1. Ouvrez la vue **Documents** dans la barre latérale.
2. Glissez-déposez un fichier PDF de cours ou collez l'URL d'une vidéo YouTube.
3. Une fois le document découpé en sections, cliquez sur **Générer des cartes** pour lancer votre première extraction.

## Étape 4 : Valider et exporter dans Anki

Relisez les cartes proposées, ajustez-les si nécessaire, puis appuyez sur <kbd>Ctrl+Alt+E</kbd> (**Exporter des cartes Anki (.apkg)**). Double-cliquez sur le fichier `.apkg` obtenu : vos cartes sont immédiatement ajoutées dans Anki !
