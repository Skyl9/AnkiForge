# Générer des Flashcards avec l'IA

AnkiDraft vous aide à transformer rapidement un chapitre dense en flashcards atomiques, tout en vous laissant le dernier mot sur chaque carte grâce à la revue humaine.

## 1. Lancer une génération par lot

1. Ouvrez la vue **Génération** (<kbd>Ctrl+4</kbd>) ou cliquez sur **Générer des cartes** depuis un document.
2. Choisissez les sections du cours à traiter dans le compositeur de lots (**Batch Slice Composer**) :
   - **Mode Direct** : chaque section cochée produit un lot de cartes dédié.
   - **Mode Automatique** : regroupe ou divise les sections selon leur longueur.
3. Sélectionnez le type de carte souhaité (*Basique Recto/Verso*, *Texte à trous / Cloze*) ainsi que le paquet Anki de destination.
4. Appuyez sur <kbd>Ctrl+Entrée</kbd> pour démarrer la génération.

## 2. Personnaliser le style des cartes (Personas)

Vous pouvez adapter le ton et l'exigence de l'IA selon votre domaine d'étude :
- **Sciences & Médecine** : définitions précises, mécanismes physiopathologiques, valeurs de référence.
- **Droit & Sciences humaines** : notions clés, distinctions conceptuelles, dates et arrêts.
- **Langues & Vocabulaire** : exemples contextualisés, expressions idiomatiques et prononciation.

## 3. Revue humaine avant enregistrement (Staging)

Aucune carte générée par l'IA n'est ajoutée aveuglément à votre collection : toutes les propositions arrivent dans la file de **Revue (Staging)** où vous pouvez les accepter, les modifier ou les rejeter en un clic.
