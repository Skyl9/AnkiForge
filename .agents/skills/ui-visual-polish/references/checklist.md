# Checklist de polish visuel

## Diagnostic

- [ ] Vue, thème, layout et état reproduits
- [ ] Capture before conservée si le défaut est visuel
- [ ] Preuve localisée dans le code ou le rendu
- [ ] Cause partagée recherchée avant l'exception locale

## Finition

- [ ] Bords et axes alignés
- [ ] Espacements cohérents avec les tokens existants
- [ ] Aucun texte tronqué ou collisionné
- [ ] États hover, focus et disabled lisibles
- [ ] États vide, chargement et erreur cohérents
- [ ] Cibles interactives et noms accessibles vérifiés
- [ ] Thèmes/layouts impactés rejoués

## Validation

- [ ] Test UI ciblé exécuté
- [ ] Ruff ciblé exécuté si code UI modifié
- [ ] Diff limité au défaut et à sa cause
- [ ] Résultat before/after décrit sans jugement esthétique vague
