# Bienvenue sur AnkiForge 🛠️

AnkiForge est un écosystème de bureau surpuissant conçu pour transformer vos sources de connaissances (PDF, Word, PowerPoint, Web) en flashcards Anki de haute qualité grâce à l'intelligence artificielle.

## Pourquoi AnkiForge ?

La création manuelle de flashcards est un processus chronophage qui freine l'apprentissage. AnkiForge automatise cette étape tout en garantissant une précision pédagogique maximale.

### Atouts majeurs :

*   **Extraction Intelligente** : Support avancé des PDF via Deep Learning (Marker), permettant de récupérer les formules LaTeX et les structures complexes.
*   **Agnosticisme IA** : Connectez-vous à vos modèles préférés, qu'ils soient locaux (**Ollama**, LM Studio) ou cloud (**Gemini**, **OpenAI**, **Groq**).
*   **Support Mathématique** : Rendu LaTeX natif et extraction propre des équations depuis Wikipédia ou vos documents scientifiques.
*   **Interface Moderne** : Une expérience utilisateur fluide développée en PySide6, pensée pour la productivité.
*   **Gestion des Médias** : Automatisation du stockage et du lien vers les images extraites des documents.
*   **Export Direct** : Génération de fichiers `.apkg` compatibles avec toutes les versions d'Anki.

## Pour qui ?

*   **Étudiants** en médecine, droit ou sciences souhaitant accélérer leurs révisions.
*   **Autodidactes** apprenant à partir de documentations techniques ou d'articles Wikipédia.
*   **Enseignants** désirant transformer leurs cours en supports de révision actifs pour leurs élèves.
